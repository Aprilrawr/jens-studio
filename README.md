# Content Studio

Your social media studio for carousels, single posts, stories, photos and post ideas. This version runs on its own website, outside Claude.

## What's in this folder

| File | What it does |
|---|---|
| `index.html` | The whole app |
| `manifest.webmanifest` | Lets the app install on your iPad home screen |
| `icon-180.png`, `icon-192.png`, `icon-512.png` | The app icon |
| `README.md` | This guide |

## Put it online with GitHub Pages (free, about 10 minutes)

You can do all of this in Safari on your iPad, or on a computer.

1. **Create a GitHub account** at github.com if you don't have one.
2. **Make a new repository.** Tap the **+** at the top right, then **New repository**.
   - Name it `content-studio`.
   - Choose **Public**. Free GitHub Pages sites need a public repository. Only the app's code is public. Your designs, ideas and photos are never stored on GitHub; they stay on your device.
   - Tap **Create repository**.
3. **Upload the files.** On the new repository page, tap **uploading an existing file** (or **Add file**, then **Upload files**). Add all the files from this folder: `index.html`, `manifest.webmanifest`, the three icons, and this `README.md`. Then tap **Commit changes**.
4. **Turn on GitHub Pages.** Go to **Settings**, then **Pages** in the left menu. Under **Build and deployment**, set **Source** to **Deploy from a branch**. Set the branch to **main** and the folder to **/ (root)**, then tap **Save**.
5. **Wait a minute or two,** then refresh that Settings page. Your link appears at the top. It will look like `https://YOUR-USERNAME.github.io/content-studio/`.

## Install it on your iPad

1. Open your new link in **Safari**.
2. Tap the **Share** button, then **Add to Home Screen**, then **Add**.
3. **From now on, always open the studio from the home screen icon.** It keeps its own storage, separate from Safari, and iPadOS doesn't clear it the way Safari can clear data for websites you haven't visited in a while.

## Bring over everything from the Claude version

1. In the Claude version, go to **Brand settings**, then **Backup**, and tap **Download backup**. Save the file.
2. Open your new studio **from the home screen icon**, go to **Brand settings**, then **Backup**, and tap **Restore from backup**. Pick the file.

Your designs, ideas, photos (with their sections), headshot, fonts and colours all come across.

## Good to know

- **Your data lives on the device you use.** The iPad and a computer each keep their own copy, and they don't sync. To move work between devices, download a backup on one and restore it on the other.
- **Back up regularly**, for example once a week, and save the file to iCloud Drive or Files. If the device is lost, reset, or the home screen app is deleted, the backup is your only copy.
- **Downloads:** PNG images, ZIPs and the editable Canva file (.pptx) download straight to your device. In Canva, choose **Import file** and pick the .pptx.
- **Brainstorm and Draft with Claude** only work inside Claude, so they're hidden here. **Make carousel** still works and starts you with a simple draft built from your saved facts.
- **Updating the app:** if you get a new `index.html`, upload it to the same repository (GitHub replaces the old one) and the site updates within a minute or two. Your data stays put.
